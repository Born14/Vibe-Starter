## The "Mobile Workflow" Angle

### What's Actually True
- Claude mobile can connect to any GitHub repo (not unique to Vibe Starter)
- Other platforms (Replit, CodeSandbox) also support mobile building
- Mobile building is a feature of Claude/AI tools, not Vibe Starter itself

### What IS Unique
- **PROMPT.md file** - Pre-written context for AI, most repos don't have this
- **Wizard guides you** - Explicitly teaches the mobile workflow exists
- **Production-ready from day 1** - Unlike sandboxes, this is real infrastructure
- **Optimized structure** - File organization designed for AI understanding

### How to Message It
✅ **Do:** "Build from anywhere - works great with Claude mobile"
✅ **Do:** "Includes PROMPT.md so AI understands your project"
✅ **Do:** "Many users build features from their phone during commutes"

❌ **Don't:** "The only way to build on mobile"
❌ **Don't:** "Revolutionary mobile building technology"

**Frame it as:** A workflow we highlight and optimize for, not a capability we invented.

## Voice & Tone

**Be:** Direct, honest, helpful
**Avoid:** Hype, exaggeration, over-promising

**Good examples:**
- "20 minutes to a deployed app" ✓ (measurable, true)
- "Build features by talking to Claude" ✓ (clear, accurate)
- "You own everything forever" ✓ (strong, true)

**Bad examples:**
- "Revolutionary AI deployment platform" ✗ (vague hype)
- "The only way to build on mobile" ✗ (factually false)
- "Build anything in minutes" ✗ (misleading - setup is 20 min, features vary)

**When in doubt:** Be more specific, less superlative.
